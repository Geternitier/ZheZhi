绘境

一屏完成选择、填写和查看。纸色速写本，铅笔勾线。初始两个服务：文生图，图生图。

原则

  • 同一时刻只呈现当前服务需要的字段。
  • 两个入口同等、并列。选中项用铅笔涂实。
  • 主操作只有一颗按钮。空闲时是「生成」，运行中是「停止」。
  • 等待和结果始终在右侧。没有结果时，用一句话说明下一步。
  • 错误放在按钮下方，一句话，不用弹窗。

两个服务

入口服务必填空状态
文生图 text.image 文本、比例 写下要画的内容，然后生成。
图生图 image.image 一张参考图、文本 放入一张参考图，并写下要怎么画。
  • 文生图显示比例，默认 2:3。选项为 1:1、2:3、3:2、16:9、9:16。
  • 图生图不显示比例。尺寸按原图比例决定，页面不提供宽高。
  • 参考图只收一张，png、jpeg 或 webp。选中后显示缩略图，可更换或移除。
  • 文本为空，或图片服务还没有图时，「生成」不可用。
  • 切换入口不取消正在进行的运行。新的表单只影响下一次提交。

区块

区块职责
入口在文生图和图生图之间切换。图生图多参考图，文生图多比例。
表单收集当前服务的输入。不填写像素。
等待显示阶段、步数和大约剩余时间。
结果显示图片、提示词和种子。

状态

phase等待区
queued排队中
sampling正在出图，并显示第几步
done完成。图进入结果区
failed按钮下显示 message。已填写的内容保留
cancelled已停止。已有的图保留
  • etaMs 为空时写「正在估计时间」，否则写「大约还需」。
  • 满一分钟用分钟，不足一分钟用秒。
  • Comfy 不可用时禁用「生成」，顶栏写「Comfy 未就绪」。

运行

  1. 文生图提交 JSON：text、ratio。
  2. 图生图提交文本和一张图，字段名为 text、image。不提交比例。
  3. 记下返回的 id，订阅 /api/runs/:id/events。
  4. done 时用事件里的 image 显示结果。
  5. 「停止」调用 POST /api/runs/:id/cancel。

运行 id 和当前入口存在 sessionStorage。刷新后先取快照；尚未结束就重新订阅。

目录

Vite，TypeScript。开发时把 /api 代理到 127.0.0.1:8741。页面是一张速写纸：米色底、横线、左侧装订孔和红边。内容居中，宽约 920px。字体用楷体。
