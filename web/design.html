折枝

一屏完成选择、填写和查看。纸色速写本，铅笔勾线。初始两个服务：文生图，图生图。

原则

  • 同一时刻只呈现当前服务需要的字段。
  • 两个入口同等、并列。选中项用铅笔涂实。
  • 主操作只有一颗按钮。空闲时是「生成」，运行中是「停止」。
  • 等待和结果始终在右侧。没有结果时，用一句话说明下一步。
  • 历史贴在结果下面，默认一行，可以展开。每个浏览器最多 12 张，新的在左。满 7 天的不再出现。
  • 错误放在按钮下方，一句话，不用弹窗。

两个服务

入口服务必填空状态
文生图 text.image 文本、比例、清晰度 写下要画的内容，然后生成。
图生图 image.image 一张参考图、文本、清晰度 放入一张参考图，并写下要怎么画。
  • 文生图显示比例，默认 2:3。选项为 1:1、2:3、3:2、16:9、9:16。
  • 图生图不显示比例。尺寸按原图比例决定，页面不提供宽高。
  • 两个入口都显示清晰度，只写标清、高清、超清，默认标清。
  • 参考图只收一张，png、jpeg 或 webp。选中后显示缩略图，可更换或移除。图生图可以把结果图和历史图拖进参考图。
  • 等待时改过的提示词，在生成完成后保留。
  • 文本为空，或图片服务还没有图时，「生成」不可用。
  • 切换入口不取消正在进行的运行。新的表单只影响下一次提交。

区块

区块职责
入口在文生图和图生图之间切换。图生图多参考图，文生图多比例。两边都有清晰度。
表单收集当前服务的输入。清晰度只显示标清、高清、超清。
等待铅笔沿曲线移动。采样进行到中段、且估得出剩余时间时，旁边写大约还需多久。不写步数。
结果图片铺满这一栏。点击后查看大图，可以放大和缩小。图生图时，这张图可以拖到参考图。
历史结果下方，新的在左。默认一行，放不下时可以展开和收起。没有记录时不显示。点一张进入查看，可以放大和缩小。查看不更换参考图，也不更换结果区和提示词。图生图时，历史图可以拖到参考图。缩略图悬停可见提示词。每张可以删除；删掉结果区正在显示的那张时，结果区回到空状态。

状态

phase等待区
queued铅笔慢慢前移，旁边不写字
sampling铅笔跟着步数走。估得出剩余时间时写「大约还需」，否则不写字
done等待区收起。图进入结果区，并出现在历史最左边
failed等待区收起。按钮下显示 message。已填写的内容保留
cancelled铅笔隐藏，写「已停止」。已有的图保留
  • 剩余时间满一分钟写分钟，不足一分钟写秒。
  • Comfy 不可用时「生成」不可用。顶栏只有「折枝」。
  • 文本标题旁有「复制提示词」。文本为空时它不可用，复制成功后短暂写成「已复制」。
  • 清晰度选中项加下划线。比例选中项的小框涂实。
  • 失败和取消不进入历史。出图期间，已有历史仍可点开。

运行

  1. 文生图提交 JSON：text、ratio、scale。
  2. 图生图提交文本、一张图和清晰度，字段名为 text、image、scale。不提交比例。
  3. 记下返回的 id，订阅 /api/runs/:id/events。
  4. done 时用事件里的 image 显示结果。
  5. 「停止」调用 POST /api/runs/:id/cancel。

运行 id 和当前入口存在 sessionStorage。刷新后先取快照；尚未结束就重新订阅。有进行中的运行时，大图区继续显示这次运行。

每个浏览器在 localStorage 的 huijing.client 保存一个 UUID。请求带上 X-Huijing-Client。同一浏览器的多个标签共用这一份历史。

打开页面时读取 GET /api/history。没有进行中的运行、且有历史时，大图显示最新一张。生成成功后再次读取，新图在最左边。页面获得焦点时也重新读取。结果区正在显示的图若已不在列表里，结果区回到空状态。

删除调用 DELETE /api/history/:id。每个浏览器最多 12 张，满 7 天的由服务端清理，页面不再显示。历史默认只显示一行，放不下时可以展开和收起。点历史图进入查看，不把它放进参考图。图生图时，把历史图拖进参考图才会换掉参考图。

目录

Vite，TypeScript。开发时把 /api 代理到 127.0.0.1:8741。页面是一张速写纸：米色底、横线、左侧装订孔和红边。内容居中，宽约 920px。字体用楷体。

文件内容
