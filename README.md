# 折枝

本机AI服务。后端封装文本、生图、生视频模型调用，按规定提供生成服务。前端提供简明易用的交互界面。

## 组成

- `server`：生成服务。
- `web`：页面。
- `shared`：前后端共用的比例、运行阶段和接口类型。

`text.image` 用文字和比例生图，比例为 `1:1`、`2:3`、`3:2`、`16:9`、`9:16`。

`image.image` 用一张参考图和文字生图，比例跟随原图。宽高按大约 `1024×1024` 的像素量取近似比例，并取 32 的倍数。

设置、耗时和结果图写在本机 `data/`，不进入版本库。

## 运行

需要 Node.js 22 或更新。

```
npm install
npm run dev
npm run dev:web
```
