# 折枝

本机AI服务。后端封装文本、生图、生视频模型调用，按规定提供生成服务。前端提供简明易用的交互界面。

## 组成

- `server`：生成服务。
- `web`：页面。
- `shared`：前后端共用的比例、运行阶段和接口类型。

`text.image` 用文字、比例和清晰度生图，比例为 `1:1`、`2:3`、`3:2`、`16:9`、`9:16`。

`image.image` 用一张参考图、文字和清晰度生图，比例跟随原图。结果图可以拖成下一张参考图。

清晰度为标清、高清、超清，像素量大约是 `1024×1024`、`1536×1536`、`2048×2048`，默认标清。宽高按该像素量取近似比例，并取 32 的倍数。

设置、耗时和结果图写在本机 `data/`，不进入版本库。

## 运行

需要 Node.js 22 或更新。

```
npm install
npm run dev
npm run dev:web
```
